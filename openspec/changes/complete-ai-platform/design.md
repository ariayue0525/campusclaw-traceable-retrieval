## Decisions

1. 班级和角色始终由 `requireAuth` 后实时读库得到。对象读取按班级及本人过滤；他班与不存在统一 404。
2. 提示词模板按班级保存名称、正文、启用状态；智能体可选绑定模板。模板只允许服务端支持的占位符，渲染后的文本进入 system 消息。智能体自身 prompt 可覆盖模板正文。
3. 技能沿用现有 `skills` 表，解析中文元数据区和说明正文。每轮只在智能体绑定且启用的技能里做确定性词法路由。
4. 新会话锁定 `agent_id`。问答读取当前智能体绑定；问题先落库，历史仅最近 6 条、每条最多 500 字。
5. 检索在 MySQL 关键字、Qdrant payload 和回表三处均约束班级与材料 ID，最后仅保留 ready 且非空的前 4 条；资料放 user 消息。
6. 网关流使用 OpenAI 兼容 `stream=true`；服务端转发增量 `delta`。首个事件为 `meta`；助手消息落库后才发送 `done`；故障发 `error`。
7. MCP 服务经内部 HTTP JSON-RPC 2.0 暴露只读教学工具。宿主登记信息与发现快照归班级；令牌仅从环境变量按服务名读取，不入库。工具 schema 与调用结果均由宿主校验、限额并记审计。
8. 第 4 课路由和前端入口保持兼容；新增接口以同源代理提供。
