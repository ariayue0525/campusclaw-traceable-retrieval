## ADDED Requirements

### Requirement: R1 多智能体与提示词模板

教师 MUST 能管理本班提示词模板并绑定智能体。学生 MUST 只能选择本班已启用智能体。会话回答 MUST 使用该智能体当前提示词或所绑定模板，空值回退到服务端默认角色。跨班模板和智能体 MUST 与不存在对象同形返回 404。

系统初始化 MUST 为每个班级提供至少两个用途不同的已启用教学 AI 应用，重复初始化不得产生重复项，也不得覆盖教师已经修改的提示词或启用状态。

#### Scenario: 本班教师维护模板

- **WHEN** 本班教师创建模板并绑定本班智能体
- **THEN** 后续会话的系统消息包含模板正文，且学生只看到本班已启用智能体

#### Scenario: 内置多应用

- **WHEN** 全新安装或已有单应用系统升级并重复执行初始化
- **THEN** 每个班级至少有解题引导与概念讲解两种内置应用，班内名称唯一且教师既有配置不被覆盖

#### Scenario: 越权读取

- **WHEN** 用户读取其他班模板或智能体
- **THEN** 服务返回与不存在资源相同的 404

### Requirement: R2 技能文件与路由

教师 MUST 能上传或编写不超过 8000 字的技能文本。解析 MUST 拒绝重复、未知、缺失、超长字段及非法工具。每轮 MUST 只在当前智能体绑定且启用的技能内按关键词匹配，最高分胜出、同分取较小 ID、零分不选择。命中技能的说明全文进入 system 消息，未命中技能不进入消息。

#### Scenario: 技能路由

- **WHEN** 当前提问命中多个已绑定技能的关键词
- **THEN** 只选最高分且同分 ID 最小的技能，并将其正文送入系统消息

#### Scenario: 非法技能文件

- **WHEN** 教师上传含重复或未知字段的技能文件
- **THEN** 服务拒绝保存且数据库不发生部分写入

### Requirement: R3 会话、限定检索与流式回答

会话 MUST 绑定创建时本班已启用的智能体，归属当前用户；他人和他班会话统一 404。每轮 MUST 使用最近 6 条消息，限定班级、智能体材料及技能资料范围检索，最多输入 4 条有效切片。无命中仍回答，引用为空。SSE MUST 按 `meta`、多次 `delta`、`done` 或 `error` 发送，`done` 在消息持久化之后。

#### Scenario: 有材料的流式问答

- **WHEN** 学生在自己的会话发送提问且绑定材料存在有效切片
- **THEN** 检索只在授权范围内执行，先收到技能和引用 meta，再收到增量 delta，持久化成功后收到 done

#### Scenario: 无检索命中

- **WHEN** 授权材料没有可用切片
- **THEN** 模型仍按角色回答且 citations 为空

### Requirement: R4 MCP 服务与工具调用

自建 MCP 服务 MUST 提供 `initialize`、`tools/list`、`tools/call` 和 Bearer 鉴权，并至少提供两个只读教学工具。教师 MUST 可登记、连接、断开本班服务；连接时握手并整体替换发现清单。模型只能看到本轮命中技能允许且当前连接的工具声明；宿主 MUST 校验参数、限制调用次数、过滤返回、记录成功／拒绝／错误，并把结果作为数据消息回传。令牌 MUST 只来自服务端环境变量。

#### Scenario: 授权工具调用

- **WHEN** 模型请求当前技能允许的已连接 MCP 工具
- **THEN** 宿主校验参数、执行工具、记录审计并将过滤后的结果作为数据消息回传

#### Scenario: 越权工具调用

- **WHEN** 模型请求未绑定、未连接或不属于本班的工具
- **THEN** 宿主拒绝执行并记录拒绝审计

### Requirement: R5 文档与验收

系统 MUST 提供 Bearer OpenAPI/Swagger，覆盖主要旧接口和新增接口。自动化测试 MUST 验证响应字段及数据库持久化，并包含跨班负向、SSE 增量和 MCP 端到端场景。现有第 4 课测试 MUST 继续通过。

#### Scenario: 完整验收

- **WHEN** 在配置好网关和本地服务的环境运行自动化验收
- **THEN** HTML 报告记录响应、持久化、跨班隔离、流式增量和工具调用结果
